Design this round

  • Fixed pages, always present, swipe left/right. 6 pages: music, noti, charging, calling, timer, custom.
  • Empty states per page — no music, no noti, not charging, no call. Page still there, just empty copy.
  • Auto-switch by feature: noti arrive → jump noti page. Charger plug → jump charging. After dismiss/unplug → return last user page. One host, no Activity race.
  • Same data sources: music = MediaSession (like current MediaView), noti = NotificationService, charge = ChargingService, call = dumpsys telephony.registry (read-only).
  • Timer/custom self-contained in MRSS; custom content still TBD.
